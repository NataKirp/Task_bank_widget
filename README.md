# Проект "Виджет для банка"

## Описание
Этот проект предоставляет виджет для работы с банковскими операциями в личном кабинете клиента банка. 
Он показывает несколько последних успешных банковских операций клиента. 

## Требования к окружению
```
Python >= 3.14
```

## Установка
1. Клонируйте репозиторий:
    ```
    git clone https://github.com/NataKirp/task_bank_widget.git
    ```
2. Перейдите в папку проекта:
    ```
    cd Task_bank_widget
    ```
3. Активируйте виртуальное окружение через __Poetry__  


4. Зависимости:

В случае отсутствия менеджера проектов __Poetry__, установите зависимости
из списка зависимостей в файле __pyproject.toml__
```
# Создание: 
pip freeze > requirements.txt

# Установка:
pip install -r requirements.txt
```

## Функционал проекта
### Модуль masks
Содержит функции для маскировки номера карты и номера счета:

#### Функция `get_mask_card_number`
Принимает на вход номер карты и возвращает ее маску. 
Номер карты замаскирован и отображается в формате XXXX XX** **** XXXX, 
где X — это цифра номера.

**Пример работы функции:**

| Входной аргумент | Выход функции       |
|------------------|---------------------|
| 7000792289606361 | 7000 79** **** 6361 |

#### Функция `get_mask_account` 
Принимает на вход номер счета и возвращает его маску. 
Номер счета замаскирован и отображается в формате **XXXX, где X — это цифра номера.

**Пример работы функции:**

| Входной аргумент     | Выход функции |
|----------------------|---------------|
| 73654108430135874305 | **4305        |

### Модуль widget
Содержит функции для работы с реквизитами счета или карты:

#### Функция `mask_account_card`
Определяет тип данных (счет или карта) и возвращает замаскированный номер. 

**Примеры входных данных для проверки функции**

MMaestro 1596837868705199  
Счет 64686473678894779589  
MasterCard 7158300734726758  
Счет 35383033474447895560  
Visa Classic 6831982476737658  
Visa Platinum 8990922113665229  
Visa Gold 5999414228426353  
Счет 73654108430135874305  

**Пример работы функции для карты**

| Входной аргумент               | Выход функции                     |
|--------------------------------|-----------------------------------|
| Visa Platinum 7000792289606361 | Visa Platinum 7000 79** **** 6361 | 


**Пример работы функции для счета**

| Входной аргумент          | Выход функции |
|---------------------------|---------------|
| Счет 73654108430135874305 | Счет **4305   |


#### Функция `get_date`
Принимает на вход строку с датой в формате "2024-03-11T02:26:18.671407" 
и возвращает строку с датой в формате "ДД.ММ.ГГГГ" ("11.03.2024").

### Модуль processing
Содержит функции для фильтрации и сортировки банковских операций:

#### Функция `filter_by_state`
Фильтрует список операций по статусу выполнения.

**Пример входных данных для проверки функции**

[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},  
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},  
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},  
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}] 

**Пример работы функции:**
```
# Выход функции со статусом по умолчанию 'EXECUTED'
[{'id': 414288290, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
 {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]

# Выход функции, если вторым аргументом передано 'CANCELED'
[{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
 {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
```

#### Функция `sort_by_date`

### Модуль decorators
#### Декоратор `log`
Логирует выполнение функций и записывает результат в файл, либо выводит в консоль

**Пример использования функции**
```
@log(filename="mylog.txt")
def my_function(x, y):
    return x + y
my_function(1, 2)
```
### Модуль utils
#### Функция `load_operations`
Принимает на вход путь до JSON-файла и возвращает список словарей с данными о финансовых транзакциях.  
Если файл пустой, содержит не список или не найден, функция возвращает пустой список.
### Модуль external_api
#### Функция `get_transaction_amount_rub`
Принимает на вход транзакцию и возвращает сумму транзакции (amount) в рублях.
Если транзакция была в USD или EUR, происходит обращение к внешнему API
для получения текущего курса валют и конвертации суммы операции в рубли.
### Модуль file_readers
#### Функция `read_csv_file`
Считывает данные о финансовых транзакциях из CSV файла и возвращает их в виде списка словарей

**Пример использования функции**
```
transactions_csv = read_csv_file('path/to/transactions.csv')
print(transactions_csv)
```
#### Функция `read_excel_file`
Считывает данные о финансовых транзакциях из Excel файла и возвращает их в виде списка словарей

**Пример использования функции**
```
transactions_excel = read_excel_file('path/to/transactions_excel.xlsx')
print(transactions_excel)
```
